# 独立高速循迹测试工程

## 重要安全提示

本工程上电后自动启动电机，不等待题号帧、启动帧或调速帧。首次烧录后应先架空驱动轮确认转向和加速过程，再放到赛道测试。

## 调整目标速度

只修改 `APP/speed_test_config.h`：

```c
#define SPEED_TEST_TARGET_MM_S (300)
```

建议依次测试 `240`、`270`、`300 mm/s`。速度以 `100 mm/s^2` 平滑增加，达到300约需3秒。

## 保留与取消的功能

- 保留8路灰度循迹、直道PD、弯道差速、编码器速度闭环、丢线恢复和30秒后终点停车。
- 保留USART1遥测，便于地面站观察状态。
- 忽略全部 `$CAR,T`、`$CAR,S` 和 `$CAR,V` 控制帧。
- 输出固件为 `OBJ/C10B_Trace_SpeedTest.hex`，不会覆盖正式工程HEX。

正式双任务稳定工程位于相邻目录 `C10B_Trace`，不要在测速工程中继续开发比赛通信逻辑。
