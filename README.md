# C10B_Trace

STM32F103RCT6（轮趣科技C10B主板）循迹小车固件，Keil MDK + 标准外设库(SPL)。

## 目录结构

- `APP/` — 循迹算法(`trace_task`)、电机控制(`app_motor`/`PID_Motor`)、里程计(`odometry`)、与地瓜派通信及指令处理(`rdk_link`/`gcs_cmd`)
- `BSP/` — 板级驱动：电机(`motor`)、灰度传感器(`Grayscale_Sensor`)、串口(`USART`)、定时器(`Timer`)
- `CMSIS/` `FWLib/` — STM32F10x标准外设库
- `USER/` — 工程入口(`main.c`)、Keil工程文件(`C10B_Trace.uvprojx`)

## 硬件

- 主控：STM32F103RCT6
- 循迹：8路灰度传感器模块（CD4051多路选通）
- 电机：GM37-520编码电机 x2，AT8236驱动
- 与上位机(RDK X5)通信：USART1，PA9=TX / PA10=RX，经板载CH9102F Type-C连接，115200-8N1

## 任务控制

- 上电后保持停车，收到题号帧和启动帧后才开始循迹。
- 第一题慢速为100mm/s；第二题启动前5秒为200mm/s，随后降至130mm/s；两题快速档均为200mm/s。
- 启动和快慢档切换采用100mm/s²速度斜坡，循迹差速修正保持实时响应。
- 运行30秒后，至少6路灰度持续检测到黑色30ms，锁存终点并停车。

| 指令 | 报文 |
|---|---|
| 第一题 | `$CAR,T,1*35\r\n` |
| 第二题 | `$CAR,T,2*36\r\n` |
| 启动 | `$CAR,S,1*32\r\n` |
| 慢速 | `$CAR,V,1*37\r\n` |
| 快速 | `$CAR,V,2*34\r\n` |

题号帧必须先于启动帧；重复题号帧和启动帧均按幂等方式处理。USART1接收端使用环形队列，可保存地瓜派连续发送的整组控制帧。
